# 🎤 발표 자료

최종 발표(데모) 관련 자료를 이 폴더에 보관합니다. **담당: 팀원 B** (제작 총괄), 리허설은 전원 참여.

## 파일 구성

```
docs/presentation/
├── slides.html      # ✅ 발표 슬라이드 (브라우저로 열기 → F11 풀스크린 → ←/→ 이동)
├── demo-script.md   # ✅ 데모 대본 (배역·리스크 대응 포함)
└── assets/          # 스크린샷, 시연 GIF (Day 2에 수집 — slides.html 5번 슬라이드에 교체 삽입)
```

- `slides.html`은 더블클릭으로 열리는 단일 파일이다. PDF 제출본은 브라우저 인쇄(Cmd+P)로 저장.
- 내용 수정은 HTML 텍스트만 고치면 된다 (7개 `<section class="slide">`가 슬라이드 1장씩).

## 슬라이드 구성 (12장 — 와이어프레임·기획 중심)

1. 타이틀 — 와이어프레임으로 보는 기획
2. 문제 (기획 배경) — 공구는 하고 싶은데 총무는 하기 싫다
3. 기획 원칙 4가지 — 버튼 한 번 / 전 구간 실시간 / 정산 자동화 / 돈 얘기 투명
4~11. **와이어프레임 워크스루** — 클로드 디자인 `공구앱 와이어프레임` 5개 턴의 장면을
   원본 그대로 재현해 넣고 장면마다 기획 의도 설명
   (전체 구조 → 상세·즉시 참여 → 올리기·팝오버 → 카테고리 → 총액 변경 → 채팅 → 정산 → 지갑·예외)
5. 마무리 — 와이어프레임 → 하이파이 → 구현 여정 + 팀

> 와이어프레임은 스크린샷이 아니라 **HTML로 원본 재현**이라 어떤 해상도에서도 선명하고 인쇄도 깨끗하다.
