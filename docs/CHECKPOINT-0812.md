## 조사 중 나온 추가 발견 (이슈 미등록, 참고)

- `profileStats`가 `store.deals` 의존 — 홈을 안 거치면 참여/주최가 0으로 표시 (#84에서 함께 처리).
- 마감 시각이 지나도 DB `group_buys.status`는 `recruiting`으로 영구 잔류 — UI 파생 표기로만 "마감" 처리 중 (설계 의도, 규칙 1).
- 충전 orderId 저장 테이블이 없어 중복 승인 방지를 토스 에러에만 의존 (의도적 — confirm 라우트 주석).
