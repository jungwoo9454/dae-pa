## 하루 운영 루틴

### 🌅 아침 (10분 데일리 싱크)

각자 3가지만 말한다: **어제 한 것 / 오늘 할 것 / 막힌 것**.
싱크 직후 각자 오늘 이슈에 self-assign + `git pull origin main`.

### ☀️ 낮 (개발 사이클)

```
이슈 self-assign → 브랜치 → 구현 → PR (300줄 이하) → 파트너 리뷰(1시간 내) → Squash 머지 → 다음 이슈
```

- 이슈 하나 = 브랜치 하나 = PR 하나. 완료 조건(체크박스)을 다 채우면 끝.
- **30분 룰**: 30분 이상 혼자 막히면 무조건 팀 채팅에 공유. 자존심보다 데모.
- 공통 파일(스키마, `lib/types.ts`, 공용 컴포넌트) 수정은 **수정 전에** 채팅 공지.
- 새 할 일이 생기면 → 즉시 이슈 등록(P0/P1/P2 라벨) → TASKS.md에도 한 줄 추가.

### 🌙 저녁 (마감 점검)

- 오늘 마일스톤(Day N) 이슈 소진율 확인 — 못 끝낸 P0는 **다음 날 아침 최우선**으로 이월
- P2는 과감히 버린다 (스코프 아웃이 실패가 아니라 전략)
- main이 배포 서버에서 잘 도는지 확인 (`docs/DEPLOY.md` 업데이트 절차)
