## 참고

- **UI는 이미 프로토타입으로 구현되어 있다** (`components/views/*`) — 각 작업은 목데이터(Zustand)를 Supabase 연동으로 교체하는 방식으로 진행한다.
- 영수증 자동 인식(Claude API)은 **보류** — 총액은 주최자 수동 입력 + 참여자 동의 투표로 확정.
- 새 작업이 생기면 이슈로 등록하고 이 문서에도 추가한다.
